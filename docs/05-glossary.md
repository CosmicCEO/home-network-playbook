# Glossary

- **ONT**: Optical Network Terminal. Converts fiber light to Ethernet; here the "AT&T device" on the exterior wall.
- **Comm panel**: structured wiring enclosure where room cabling converges.
- **Cat6 / Cat6e**: twisted-pair Ethernet cable, rated for gigabit (and 10 Gbps over shorter runs). "Cat6e" is a common informal label for Cat6.
- **POTS**: plain old telephone service. A POTS (RJ11-style) termination uses only 2 to 4 conductors, not all 8 that Ethernet needs.
- **RJ45 / keystone**: 8-conductor Ethernet connector and its punch-down jack module.
- **568B**: standard pin/colour order for terminating Ethernet; use the same at both ends.
- **RG6**: 75-ohm coaxial cable.
- **MoCA**: Multimedia over Coax Alliance. Carries Ethernet over existing coax using frequencies above those of TV.
- **POE filter**: Point-of-Entry filter. Blocks MoCA signals from leaving the house on coax (not Power over Ethernet).
- **PoE**: Power over Ethernet.
- **Splitter rating**: frequency range a splitter passes; MoCA 2.x needs up to 1675 MHz.
- **Mesh point**: secondary Wi-Fi node (Nest point) that extends the primary hub.
- **Backhaul**: the link between mesh nodes; wired is faster and more reliable than wireless.
- **Double NAT**: two routers in a row each translating addresses; usually avoidable with passthrough or bridge mode.
- **IP Passthrough**: gateway feature that hands its public IP to a downstream router.
- **iperf3**: tool for measuring network throughput between two machines.
